## 🕵️‍♀️ مهم‌ترین بخش: چیزهای مخفی

این سایت چندین **Easter Egg و Secret Interaction** دارد.

بعضی‌هایشان با کلیک کردن پیدا می‌شوند، بعضی با تعامل چندباره با یک عنصر، و بعضی‌ها حتی ممکن است با **کیبورد** کشف شوند.

پس:

> **به هیچ چیز فقط به چشم دکور نگاه نکن.** 👀

ممکنه یک ماه، یک قلب، یک ستاره یا حتی یک دکمه، چیزی بیشتر از چیزی باشه که به نظر میاد.

---

## 🎮 چند قانون برای بازی

هیچ راهنمای کاملی وجود نداره.

خودت باید کشفشون کنی. 🌙

فقط این‌ها رو یادت باشه:

* روی چیزهای مختلف کلیک کن.
* بعضی چیزها رو چند بار امتحان کن.
* ستاره‌ها رو بررسی کن.
* ماه رو فراموش نکن.
* نامه‌ها رو باز کن.
* Puzzle رو حل کن.
* به صفحه‌کلید هم بی‌توجه نباش.
* و مهم‌تر از همه، **تا آخر برو.**

چون پایان سایت، واقعاً پایانش نیست. 👀

## 🎵 موسیقی

برای فعال شدن موسیقی، فایل زیر باید کنار `index.html` قرار داشته باشد:

```text
music.mp3
```

بعد از داخل سایت می‌توانی آن را پخش یا متوقف کنی.

---

## 📱 ساخته‌شده برای موبایل و دسکتاپ

این پروژه Responsive است و برای:

**📱 موبایل | 📲 تبلت | 💻 دسکتاپ**

طراحی شده.

همچنین ساختار پروژه قابلیت استفاده به شکل **PWA** را دارد.

---

## 🛠️ ساخته‌شده با

* HTML5
* CSS3
* Vanilla JavaScript
* Canvas API
* Intersection Observer
* Pointer Events
* Service Worker
* Cache Storage

بدون Framework و بدون Backend.
